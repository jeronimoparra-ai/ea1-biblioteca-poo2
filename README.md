# EA1 – Diagrama de Clases UML: Sistema de Biblioteca

Repositorio del trabajo colaborativo de la Evidencia de Aprendizaje 1 (EA1) de la asignatura **Programación Orientada a Objetos II**, IU Digital de Antioquia.

## Objetivo

Diseñar un diagrama de clases UML que modele un sistema de biblioteca, aplicando abstracción, encapsulamiento, herencia, polimorfismo y principios SOLID.
